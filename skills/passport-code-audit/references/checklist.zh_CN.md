# 合规与流畅性检查表

本表用于收集证据，不替代阅读代码。每行标记 PASS／FAIL／N/A／NOT RUN，并写明
准确命令、文件、行号或测量值。没有明显问题不等于 PASS。

## 合规

| 检查 | 需要收集的证据 |
| --- | --- |
| 仓库规则 | 已读 AGENTS/PROJECT/贡献/安全规则；例外已记录 |
| 构建门禁 | static 与完整门禁命令、警告、退出码 |
| 宿主测试 | 测试名称、结果；跳过项及原因 |
| 改动范围 | diff、调用方、共享契约影响已审 |
| 内存所有权 | 分配／释放点、退出清理、空值／错误路径、边界 |
| 整数／格式安全 | 不可信长度与索引运算；无无界拷贝／格式化 |
| LVGL 锁 | 跨任务访问均加锁；不在持锁时做阻塞 I/O |
| 任务模型 | 栈大小、优先级、队列／事件所有权、循环可被看门狗接受 |
| 阻塞热路径 | 渲染／输入中无 Flash、网络、文件、串口等待或长延时 |
| 堆纪律 | 无逐帧分配／碎片化；已评估最大连续块风险 |
| 密钥／日志 | 源码、日志、截图、提交中无凭据、token、设备密钥 |
| 网络／TLS | 超时、证书策略、错误处理、重试有界 |
| 依赖／许可证 | 新依赖与第三方声明已审 |
| 产物／配置 | 分区、布局、sdkconfig 改动有意图且已记录 |
| 门禁完整性 | 未禁用测试／警告，未压制失败，未遗留调试代码 |
| 失败恢复 | 失败可见且有界；无无限重试或破坏性修复 |

## 流畅性

| 测量项 | 证据 |
| --- | --- |
| 帧节奏 | 渲染／显示耗时或面板节奏；采样数与场景 |
| 丢帧／黑屏 | 观察计数或探针结果 |
| 输入延迟 | UP/DOWN/OK 短按／长按／双击；漏触／重复触发 |
| 堆 | 代表性游玩前后的空闲／最小堆与最大块 |
| PSRAM | 适用时的空闲／最小值 |
| 稳定性 | 看门狗复位、分配失败、崩溃、撕裂 |
| 温度／功耗 | 仅功能或板级验收需要时 |

## 结论

分别记录 Build、Host tests、Compliance、Smoothness、Device。设备或必要探针
不可用时写 `NOT RUN` 并列出剩余动作。P0/P1 发现阻塞完成与发布。
